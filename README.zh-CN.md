## 为什么选择 Blakcat

- 🔒 **始终安全。** 咖啡馆、酒店、机场的 Wi-Fi 都可以放心用。流量全程加密，你访问了什么，中间谁也看不到。
- 🌍 **想去哪就去哪。** 自有节点覆盖全球主要地区。常用的搜索、视频、社交和开发者服务开箱即用，不需要为每个网站单独折腾设置。
- 🧭 **智能路由。** 本地网站直连、其余走加密隧道，客户端自动判断。速度和隐私不用二选一，直连哪些地区自己指定。
- 🔄 **始终在线。** 断线自动重连，休眠唤醒后自己恢复，节点出问题自动切到健康节点。开启后台常驻，不打开 App 也在保护。
- 📱 **跨平台统一体验。** 多平台同一套核心，一个账号管理所有设备，换台机器不用重新学一遍。

## 反馈
