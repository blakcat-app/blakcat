# Security Policy / 安全策略

**Please do not report security vulnerabilities in a public issue.**
**请勿通过公开 Issue 报告安全漏洞。**

Report privately instead / 请通过以下任一方式私下报告：

- [GitHub Security Advisory](../../security/advisories/new)
- support@blakcat.app, subject prefixed `[SECURITY]` / 标题以 `[SECURITY]` 开头

Please include the affected version and platform, and steps to reproduce.
We aim to respond within 72 hours.

请附上受影响的版本与平台，以及复现步骤。我们会在 72 小时内首次回复。

Fixes are provided for the latest release only.
仅最新发布版本提供安全修复。
